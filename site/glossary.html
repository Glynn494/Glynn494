Glossary

Element
Opening tag, closing tag, and content of a HTML code.
Attribute
Contains information about an element and used for styling and scripts.
Character Sets
Code defined that allows you to use characters.
Favicon
An image displayed on a tab or bookmark.
Header
An element that is used to mark intro content.
